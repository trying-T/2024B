# 第三问符号表记录

本文件保存从《第三问论文初稿》中移出的主要符号表，供公式核对和后续统一编制全文符号说明时使用。

| 符号 | 含义 | 单位或取值 |
|:---:|---|:---:|
| $i,j,t$ | 零配件编号、半成品编号、生产轮次 | $i=1,\ldots,8$；$j=1,2,3$ |
| $p_i,p_j^{(s)},p_f$ | 零配件、半成品装配和成品装配次品率 | — |
| $x_i,h_j,y$ | 新购零配件、半成品和成品检测决策 | 0或1 |
| $\delta_j,z$ | 不合格半成品和不合格成品拆解决策 | 0或1 |
| $r_i,u_i$ | 回收零配件检测与利用决策 | 0或1 |
| $s_j,v_j$ | 回收半成品检测与利用决策 | 0或1 |
| $A_{i,t}^{(p)},A_{j,t}^{(s)}$ | 回收零配件、回收半成品是否存在 | 0或1 |
| $Q_{i,t}^{(p)},Q_{j,t}^{(s)}$ | 库存中回收对象的真实质量 | 0或1 |
| $G_{i,t},G_{j,t}^{(s)},G_t^{(f)}$ | 投入零配件、半成品和成品的真实质量 | 0或1 |
| $R(S)$ | 策略 $S$ 完成一次合格交付的净收益 | 元 |

质量变量取1表示合格，取0表示不合格；决策变量取1表示执行相应操作。
