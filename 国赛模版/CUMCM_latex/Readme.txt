本模板为广东赛区国赛模板，请勿擅自修改cumcm.cls文件的内容，里面定义了论文格式。

overleaf在线编译：
使用overleaf进行编译时，请设置左上角Menu->Compiler为XeLaTex.

本地编译：
编辑论文时使用cumcm.tex文件.
Windows, Linux操作系统请安装texlive (课程网页相关工具里可下载), 用Xelatex编译。
注意：Ctex下, 用xelate编译可能会报错. 
Mac OS 请安装Texshop及texlive，用Xelatex编译。如果系统字体缺失，可能需要安装中文字体库，具体安装方法请网上搜索。
